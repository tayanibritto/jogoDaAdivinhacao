Título: O Jogo da Adivinhação

Descrição: Neste jogo, o código irá gerar um número aleatório entre 1 e 100, e você terá que adivinhar qual é esse número. O jogo te dará pistas, dizendo se o número chutado é maior ou menor que o número secreto. O jogo termina quando você acertar o número ou quando ele atingir o número máximo de tentativas.

Tecnologias utilizadas: HTML5, CSS3, JavaScript

Pré-requisitos: Navegador atualizado (projeto foi testado e funciona no Google Chrome Versão 142.0.7444.163 64 bits - Caso utilize este navegador, recomenda-se tal versão ou superior)

Instalação:

Passos para clonar e rodar: git clone https://github.com/tayanibritto/jogoDaAdivinhacao.git cd jogoDaAdivinhacao abrir index.html no navegador
Como usar: Digite um número de 0 a 100 e clique em "chutar". Caso queira recomeçar o jogo, clique em "recomeçar".
Estrutura do Projeto: index.html programa.js style.css
